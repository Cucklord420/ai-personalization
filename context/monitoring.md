## Watch and discovery-feed behavior

<a id="record-watch-material"></a>

- **watch-material** — For assigned watches, alert only on verified material changes that affect an actual decision: eligibility, useful capability, compatibility, price/TCO, privacy/security or credible reliability evidence.

  required; active; retrieved_explicit/high; last supported: unknown; sources: S02, S03, S06

<a id="record-watch-quiet"></a>

- **watch-quiet** — No 'no changes' messages, recycled stories, routine cosmetics, marketing filler or speculative urgency. Seed a baseline from accessible history; baseline collection alone is not a new event.

  required; active; documented/high; last supported: unknown; sources: S06, S07

<a id="record-watch-no-duplicates"></a>

- **watch-no-duplicates** — Inspect real tasks, schedules, scope and last reported state before creating or transferring a watch. A ChatGPT watch is not automatically a Muse or other-agent watch; never duplicate one because this profile was loaded.

  required; active; documented/high; last supported: unknown; sources: S06

<a id="record-watch-status"></a>

- **watch-status** — A stored interest or checklist does not prove a running job. Inspect actual tools and records before claiming monitoring, cross-app access, reminders or notification delivery.

  required; active; documented/high; last supported: unknown; sources: S05, S06

<a id="record-watch-state"></a>

- **watch-state** — Keep last attempted check, last successful check, last material finding and last confirmed alert/delivery distinct. Preserve good prior state on failure; a failed check is not a successful unchanged result.

  required; active; documented/high; last supported: unknown; sources: S06, S07

<a id="record-watch-cadence"></a>

- **watch-cadence** — Use the assigned cadence and preserve existing schedules. The saved Muse default notification window is 09:00–21:30 America/New_York; an explicitly assigned delivery time takes precedence. Do not impose that window universally on unrelated apps.

  required; active; documented/high; last supported: 10-08-2026; sources: S06

<a id="record-watch-feed"></a>

- **watch-feed** — The discovery feed complements the material-change Tech Watch: practical discoveries, useful explanations and selective entertainment. Avoid routine launch recaps and repetitive shopping posts; do not force a daily quota.

  required; active; documented/high; last supported: unknown; sources: S07

<a id="record-watch-feed-style"></a>

- **watch-feed-style** — For discovery-feed posts, normally use 80–140 words: descriptive headline, what matters, relevance to owned equipment/interests, limitation, cost/TCO where relevant and direct evidence. Deduplicate by finding and takeaway, not just URL.

  required; active; documented/high; last supported: unknown; sources: S07

<a id="record-watch-private"></a>

- **watch-private** — Keep personal records, financial/medical details, workplace/client data, contact details and security information out of notification previews and public task logs.

  required; active; documented/high; last supported: unknown; sources: S06
