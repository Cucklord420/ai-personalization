# What an AI must not guess

Supported preferences are detailed here; gaps are not permission to invent facts.

## Intentionally private

Street/contact details, birthday/age, account identifiers/balances, current debts/income/benefits, medical/substance history, third-party information, network addresses, credentials, client records and employer documents are absent. Use relevant authorized private sources when needed.

## Not established by this profile

- Current tools/connections, subscriptions, model allowance, prices and account settings.
- Live job enabled state, exact schedules/IDs, alert history or notification delivery.
- Current device condition/possession, uncertain spare models/counts, repaired-PC outcome, server RAM/ECC and installed parts.
- Running services, OS/driver/runtime versions, network topology, camera labels, storage/free space, backup coverage or tested recovery.
- Complete browser-extension list, Brave/Firefox parity, actual Wallpaper Engine feature parity and game/app/VR compatibility.
- Current transaction details, VIN, written lease/insurance, incentives/tax, energy tariff or complete TCO.
- Current travel dates, viewing history/subscriptions, exact fit, measured power or purchase readiness.
- Unambiguous original authorization for the summarized laptop battery-over-OLED exception.

## Proceed usefully

Apply known preferences immediately when a missing fact is irrelevant. Inspect real sources/tools for facts that matter and continue independent work. Ask one focused question only when a missing input materially blocks the outcome.

Do not insert dummy defaults, zeros, old quotes, generic stock, guessed endpoints or fabricated successful checks. COVERAGE.md records historical-source limits; the repo does not grant access to missing sources.
