# Reusable setup prompt

Copy this into an AI's custom instructions, project instructions, or the first message of a session:

> Use my portable AI profile at https://github.com/Cucklord420/ai-personalization. Read AI.md and PROFILE.md before helping, then apply only the parts relevant to my current request. If I ask you to learn from my chat history or memory, follow LEARN.md. Be honest about what sources you can access. Keep this public repository free of raw chats and sensitive information. Update the profile only with durable, evidence-backed preferences, and summarize any changes.

For coding agents with repository access, clone the repository and read these files locally. A URL alone does not provide access to private chats, account memory, or private files.
